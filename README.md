## Local Preview
From the project folder, open the static site in your default browser. Use the command that matches your terminal:

**Command Prompt** (`C:\...>`):

```cmd
start "" "index.html"
```

**PowerShell** (`PS C:\...>`):

```powershell
Invoke-Item .\index.html
```

For automatic browser refresh while editing in VS Code, right-click `index.html` and choose **Open with Live Server** if you have the Live Server extension installed. Python is not required.
